    Loot filter — base items

    A base's Unique / Set drops can be hidden in the in-game loot filter once every grail item on that base is perfect (non-eth and eth — items marked “cannot be eth” only need the non-eth one). Pills show perfect / total; green = hide.
    Copy filter profile copies a Grail profile with two rules, Hide Set and Hide Unique, listing every base that can be hidden. Import it in game, then copy the two rules into your active filter (replacing your old grail rules). Copying the profile counts as updating your filter.
    Loot Filter Plus (D2RLoader plugin): tick it to split the unique rule by ethereal, so a base's non-eth uniques are hidden once its non-eth items are perfect, and its eth uniques once its eth ones are (pills N / E). The profile then has Hide Unique Non-Eth and Hide Unique Eth rules, which carry their condition: with the plugin (0.14 or later) running, importing the copied profile gives it to the imported Grail profile. If you copy the rules into another profile, Copy conditions copies the plugin sections for it: type that profile's name, paste the text at the end of d2rloader\config\loot-filter-plus-rules.toml in the game folder, then type lf-reload in the console. That is needed once (again only if you rename the profile). Without the plugin, both rules hide every unique on their bases.
    Changelog

    1.1

    • Chronicle check: load your shared stash file (.d2i) to read the in-game Chronicle from it and list what it has that the tracker doesn't (with what dropped it and when, and a button to mark it found), and what the tracker has that the Chronicle doesn't. Once everything matches, the check closes until you load a new file. The file is read in your browser and never uploaded.
    • Loot filter export: Copy filter profile copies a Grail profile with a Hide Set and a Hide Unique rule listing every base that can be hidden, ready to import in game and copy into your active filter.
    • Loot Filter Plus export: tick Loot Filter Plus to hide non-eth and eth uniques separately (the plugin's ethereal condition): a base's non-eth uniques are hidden once all its non-eth items are perfect, even while its eth ones are not, and the other way round. The profile gets Hide Unique Non-Eth and Hide Unique Eth rules carrying their condition, which the plugin (0.14+) applies when you import the profile; Copy conditions copies their sections for loot-filter-plus-rules.toml, for rules copied into another profile. A rule with no base to hide is exported turned off, since an empty rule would hide every unique or set.
    • Perfect rolls: the item popup lists the perfect value of every variable affix and the perfect total defense (non-eth and eth). Items whose affixes are all fixed only have a Perfect checkbox; ones you had marked found count as perfect.
    • Loot filter helper: the per-base pending markers and the “I have updated my loot filter” button are gone; copying the profile records the update, and the status line shows when you last updated and how many unique / set bases updating now would hide. The trees start collapsed.
    • The page scrolls horizontally when the window is narrower than the layout.
    • Item sizes: 14 unique tiles now have their base item's real inventory size (e.g. Steeldriver is 2x3).

    1.0

    • Grail tracking for Reign of the Warlock 3.3: uniques (non-eth and eth), sets, runewords and runes. Right-click an item to set its status; runes are ticked with a left-click.
    • Chronicle and Grail progress tiles, per-tab group progress, recent updates, and a search that highlights items and the tabs containing them.
    • Storage strategies: Tracking only (tree view), Extended Stash 16x16 with 20 tabs, Vanilla Stash 10x10, and Vanilla mules (10x10 stash + 10x4 inventory per mule). Switch at any time without affecting your data.

    • Backup: progress is saved in your browser; Export / Import a JSON file to back up or move it.
