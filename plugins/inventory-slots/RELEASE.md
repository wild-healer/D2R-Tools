# Inventory Slots 1.0.2: release texts

## Patch notes

```
**Inventory Slots 1.0.2**

**Fixed**

* Sort Inventory no longer moves items into or out of the slots.
* Vendor items are no longer moved around when a vendor's grid has the same size as your inventory.
* Items no longer disappear when another mod changes the inventory size; the slots turn off instead.
* On an inventory that is already 16 rows tall, the slots turn off and hide, and the log says why.
```

## GitHub release

- Tag: `inventory-slots-v1.0.2`
- Title: `Inventory Slots 1.0.2`

Body:

```markdown
**Inventory Slots** 1.0.2: Sort Inventory, vendor and resized inventory fixes.

### Fixed
- Sort Inventory no longer moves items into or out of the slots. A stray item sitting in a slot row moves back into the grid.
- Vendor items are no longer moved around when a vendor's grid has the same size as your inventory.
- Items no longer disappear when another mod changes the inventory size; the slots turn off instead and the log says why.
- On an inventory that is already 16 rows tall (the most a save can hold), the slots turn off and hide.

### Install
Load `inventory-slots-1.0.2.zip` in D2RMM in place of 1.0.1. Settings are kept.
```
